# `internal/controllers/web`

The `web` command's controller. One HTTP listener serves three unrelated things,
and `handler.go` decides which one a request belongs to before anything else
runs.

## One listener, three branches

```
                          aimem web  →  127.0.0.1:8888
                                     │
                                     │  newHandler(api, spa, mcp)
                                     ▼
                    ┌────────────────────────────────┐
                    │   switch on the path prefix    │
                    │   (internal/controllers/web/   │
                    │          handler.go)           │
                    └───────────────┬────────────────┘
                                    │
        ┌───────────────────────────┼───────────────────────────┐
        │                           │                           │
  HasPrefix(path,             HasPrefix(path,            everything else
     "/mcp")                     "/api/")
        │                           │                           │
        ▼                           ▼                           ▼
  ┌───────────┐             ┌─────────────────┐         ┌──────────────────┐
  │ MCP       │             │ generated API   │         │ the SPA          │
  │ endpoint  │             │ (ogen, from     │         │ (spa.go)         │
  │           │             │  openapi.yaml)  │         │                  │
  └───────────┘             └─────────────────┘         └──────────────────┘
        │                           │                           │
  http.Handler              server.Server                embedded ui/dist
  built by the              + Methods                    index.html rewritten
  MCP adapter                                            with the auth flag
        │                           │                           │
        ▼                           ▼                           ▼
  tools/call with           POST /api/v1/fact            GET /            → index.html
  a bearer token            POST /api/v1/search          GET /assets/x.js → unchanged
                            GET|DELETE /api/v1/fact/{id}
```

The order of the cases is the contract: `/mcp` first, then `/api/`, then the
fallback. A path that begins with neither prefix is a file, which is why the SPA
branch is the `default` and not a fourth case.

**Why a handler and not `server.WithNotFound`.** With a not-found hook, a typo
inside a prefix — `/api/v2/search` — would fall through to the SPA and be
answered with `index.html` and status 200. Splitting on the prefix here means
such a path still reaches the API branch and gets a JSON `404` instead. The
prefix is matched with `strings.HasPrefix`, not by equality, so every path
below `/api/` stays on the API side.

## The three branches

| Branch          | Entry                                                     | Owns                                                                                                                                                                   |
| --------------- | --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/mcp`          | `mcpHandler` — an `http.Handler` injected by `scaffold`   | Nothing in this package. The MCP adapter builds its own server, register its tools and its streamable-HTTP transport. `web` only decides that this path belongs to it. |
| `/api/`         | `server.Server` — generated by `ogen` from `openapi.yaml` | The contract: `openapi.yaml` is the source of truth, `server/` is generated (`make generate`), `methods.go` holds the hand-written side.                               |
| everything else | `spa.go`                                                  | The embedded Vite build, plus the auth flag injected into `index.html`.                                                                                                |

The two hand-written sides of the API are `methods.go` (the five operations) and
`controller.go` (`HandleBearerAuth`, the listener, the constructors). The mapping
from a domain error to an HTTP response lives in `error_handler.go` and is the
only place that knows about status codes.

## Authentication and the flag

`authRequired` is fixed by the constructor — `NewWithAuth` or `NewWithoutAuth` —
and never changes afterwards. It is the same answer that `scaffold` gave when it
chose which constructors to call, so this package contains one branch and no
policy:

```
scaffold ──┬─ authRequired == true  ──► NewWithAuth    → authRequired: true
           └─ authRequired == false ──► NewWithoutAuth → authRequired: false
```

That one field then decides three things, all of which must agree:

1. `HandleBearerAuth` resolves the token only when the mode is on.
2. `Methods.getUserID` checks the mode _before_ reading the context, so with auth
   off the user is never looked up — a stale value cannot reach a store that
   ignores it.
3. `newSPAHandler(authRequired)` bakes `<script>window.requireAuth=…</script>`
   into the served `index.html`.

Point 3 is why there is no `GET /api/v1/auth` endpoint: the server already knows
the answer when it builds the page, and a separate endpoint would let the page
and the handlers drift apart. The flag must be in `<head>`, before the entry
module runs — `injectAuthFlag` inserts it there and only rewrites
`index.html`, never a hashed asset.

## Rules for changing this package

- **`mcpHandler` is a plain `http.Handler` field, and must stay one.** Importing
  the MCP adapter to name its concrete type would tie a controller to an adapter,
  which `AGENTS.md` forbids. `scaffold` builds it and passes it in.
- **Do not add a second listener.** The MCP endpoint shares this port on purpose,
  so one token and one origin cover both.
- **The SPA has no fallback route.** The app uses `HashRouter`, so the server only
  ever sees `/`; a missing file is a `404`, not a client-side route.
- **`openapi.yaml` is the contract.** Change it, then run `make api-generate`
  once — it regenerates both the Go server and the UI client types. Never edit
  either generated tree by hand. The contract is `camelCase` (`createdAt`); the
  domain field is `CreatedAt`, and only the storage payloads use `created_at`.
