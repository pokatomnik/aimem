1. Все тексты в SPA должны быть на английском. Не нужно делать ни интернационализацию, ни оставлять их на русском
2. Надо добавить поддержку абсолютных импортов чтобы модули можно было импортировать как `import {Something} from 'src/shared/module'` или `import {Something} from 'shared/module'` или `import {Something} from '@/src/shared/module'`, ну ты понял меня в общем.
3. `useNavigate` нельзя использовать в `pages`. У тебя есть слой `app`, там нужно определить все возможные инварианты навигации: именно там нужно создать типизированные колбеки, которые будут принимать типизированные аргументы. И именно там можно использовать `useNavigate`. А в каждый page ты будешь с помощью `props` прокидывать эти колбеки. Это сузит количество инвариантов которые каждый page сможет использовать.
4. Вот тут internal/controllers/web/ui/src/pages/search/SearchPage.tsx сообщение о том что ничего не найдено нужно вынести в отдельный компонент. Нельзя перегружать компонент самой страницы ответственностью.
5. Вот этому internal/controllers/web/ui/src/shared/lib/paths.ts место в app, см пункт 3
6. Проверь что нет хардкода baseURL: он должен использовать абсолютный путь при вызове fetch `/api/v1/...`, потому что baseURL **всегда** будет равен текущему хосту. Клиент и сервер не будут разделены на разные домены/приложения.
